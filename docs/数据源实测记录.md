## 二、逐条证据

### 2.1 股票列表没有行业字段

```
ak.stock_info_a_code_name() -> 5569 行，列 = ['code', 'name']
第一行：{'code': '000001', 'name': '平安银行'}
```

带行业的 `ak.stock_individual_info_em(symbol="600519")` 属东财系，本机不可达。
**处理**：`stock_basic.industry` 列保留但 V1 留空，界面上不显示行业。

### 2.2 新浪 / 腾讯返回的是英文列名，且单位与东财不同

```
新浪 stock_zh_a_daily 列：date open high low close volume amount outstanding_share turnover
腾讯 stock_zh_a_hist_tx 列：date open close high low volume turnover amount
东财 stock_zh_a_hist   列：日期 股票代码 开盘 收盘 最高 最低 成交量 成交额 振幅 涨跌幅 涨跌额 换手率
```

单位差异（同一天 600519，2026-09-23）：

| | 成交量 | 换手率 | 涨跌幅 |
|---|---|---|---|
| 东财 | 30981 手 | 0.25 % | 直接给出 |
| 新浪 | 3098122 股 | 0.002478（小数） | **不提供** |
| 腾讯 | 3098122 股 | 有 | **不提供** |

**处理（归一化层必须做）**：
- `volume`：股 ÷ 100 → 存成"手"，与 `kline.volume` 定义一致
- `turnover`：小数 × 100 → 存成百分数
- `pct_chg`：新浪/腾讯都要用 `close/preclose - 1` 自己算
- 数值类型：东财返回的是**字符串**（`'609.98'`），必须 `to_numeric`

### 2.3 两家的前复权序列差异巨大 —— 本次最重要的发现

600519，2019-01-02 ~ 2026-09-24，1877 个交易日：

```
              新浪qfq    腾讯qfq    不复权
2019-01-02    499.57     325.18     598.98
2020-03-30    907.32     812.74    1072.00
2022-09-15   1642.47    1678.73    1880.00
2025-03-13   1448.67    1458.19    1537.77
2026-09-24   1237.00    1237.00    1237.00   <- 最新日三家一致
```

统计：开盘价平均相差 **3.93%**、最大相差 **56.25%**，1877 天里有 1758 天差异超过 0.1%、1104 天超过 1%。

原因：两家除权除息算法不同，但**都以最新价为锚**，所以越久远的日期差异越大。

**这条直接改变了设计**：原来只打算"检出混源并提示"。实测证明拼接是危险的——把新浪的 2019~2022 段和腾讯的 2023~2026 段拼在一起，会在拼接日凭空产生几十个百分点的跳变，**伪造出根本不存在的买卖信号**。

因此 V1 的取数策略改为：
1. **一只股票一个上游**。整段区间从同一个上游下载。
2. 主源失败 → 换下一个上游**重下整段并覆盖**，不做"缺哪补哪"。
3. 库里若检出同一 `(code, period)` 存在多个 `source`，按**数据完整性错误 fail-closed 拒绝回测**，并提供 `[整段重新下载]` 修复入口。

### 2.4 指数代码的前缀和个股不是一套规则（自检抓到的真 bug）

`fetch_index_daily` 最初直接复用个股的 `market_prefix()`，于是 000300 被拼成 `sz000300`：

```
ak.stock_zh_index_daily(symbol="sz000300")  ->  KeyError: 'date'   （新浪返回空表）
ak.stock_zh_index_daily(symbol="sh000300")  ->  6000 行 ✅
```

指数由中证/国证编制，跨市场指数统一挂沪市，所以 000 开头是 `sh`、399 开头才是 `sz`。

处理：新增 `config.INDEX_PREFIX` + `index_symbol()`，并在自检 `t13_index_symbol_uses_index_rule` 里把这个坑钉死。

备源情况也测了：
```
ak.stock_zh_index_daily_tx(symbol="sh000300")  -> 5218 行，但分 22 页拉，约 90 秒
ak.index_zh_a_hist(symbol="000300")            -> RemoteDisconnected（东财系，同 §2.7）
```
所以指数只把腾讯当"新浪彻底失败时的备胎"，并且只有 close 用于对比曲线，慢一点可以接受。

### 2.5 PE / PB 是稀疏序列，不能逐日回测

```
period='近五年' -> 914 行，2021-09-25 ~ 2026-09-25，平均间隔 2.0 天
period='近十年' -> 731 行，2016-09-27 ~ 2026-09-25，平均间隔 5.0 天
period='近1年'  -> 611 行，2001-09-06 ~ 2026-09-25，平均间隔 15.0 天（period 参数行为不可靠）
列 = ['date', 'value']，一次只能取一个指标
```

交易日大约 244 天/年，而这里 2 天甚至 15 天才一个点。要用于逐日条件判断必须前向填充，会引入误差；而且 `period` 参数返回的区间与字面不符，无法保证覆盖回测区间。

**处理**：`PE` / `PB` 移出 V1 指标白名单（白名单从 24 个降为 22 个），`valuation` 表只存"最近一期"值供个股信息卡展示。列入 §8.1 推迟到 V2 再找更密的源。

### 2.5 baostock 在本机彻底不可用

```
socket.gethostbyname('www.baostock.com') -> 114.94.20.92
tcp 80    -> OK
tcp 10030 -> TimeoutError
bs.login() -> {'error_code': '10002007', 'error_msg': '网络接收错误。'}
```

baostock 的数据服务不走 HTTP，走 `www.baostock.com:10030` 的自有 TCP 协议（见 `baostock/common/contants.py: BAOSTOCK_SERVER_PORT = 10030`）。本机网络只放行 80/443。

**处理**：代码里保留 baostock 适配器（换网络环境可能就能用），但**默认顺序里不含它**，设置页可手动开启并 `[测试]`。不能让用户以为有这层兜底。

### 2.6 东财系接口本机不稳定

`stock_zh_a_hist` / `index_zh_a_hist` / `stock_zh_a_spot_em` / `stock_individual_info_em` / `stock_zh_a_hist_min_em` 全部出现 `ConnectionError: RemoteDisconnected`，5 次退避重试（间隔 3 秒）无一成功。偶尔一次 `stock_zh_a_hist` 成功过（1877 行），说明是**服务端或中间网络限流**，不是代码问题。

**处理**：东财排第三顺位。前两级（新浪、腾讯）实测稳定。

### 2.7 60 分钟线不可用

```
ak.stock_zh_a_hist_min_em(symbol='600519', period='60') -> 124 行（东财，本机偶发可用时）
124 根 60 分钟 ≈ 31 个交易日
```

一个月的数据无法做任何有意义的回测。原计划"V2 实测后再决定"，现在实测结论明确：**移出计划**。

## 三、对代码的直接影响清单

| 影响点 | 具体改动 |
|---|---|
| `config.DEFAULT_SETTINGS["datasource_order"]` | `"akshare,baostock"` → `"sina,tencent,eastmoney"` |
| 新增设置项 | `gap_tolerance_pct = "5"`（PRD 早就要求，之前漏了） |
| `kline.source` 取值 | `sina` / `tencent` / `eastmoney` / `baostock` |
| `market_prefix()` | 修了一个真 bug：`92xxxx`（北交所）原来被 `"9"` 规则误判成沪市，现已把 `4/8/92` 判断提前 |
| 新增 `config.index_symbol()` | 指数前缀不能套个股规则（000300 → `sh000300`，见 §2.4）；指数备源用腾讯（慢，仅兜底） |
| 归一化层 | 统一转 float、成交量股→手、换手率×100、自算 `pct_chg` |
| 取数策略 | 整段单源；换源整段覆盖；混源 fail-closed |
| 指标白名单 | 22 个（去掉 PE/PB） |
| 股票列表 | 5569 只，行业留空；市场由代码前缀推断；拼音由 pypinyin 生成 |
